## About Me

I'm a researcher and software engineer interested in building secure, reliable, and intelligent digital systems.

My work brings together cybersecurity research, digital forensic investigation, and software development — from analyzing digital evidence to engineering applications and security-oriented solutions.

- **Research:** Cybersecurity, phishing URL analysis, digital forensics, and machine learning.
- **Engineering:** Web applications, mobile development, backend systems, and API integration.
- **Interests:** Digital evidence analysis, security automation, and privacy-aware technology.

> *Researching threats. Engineering solutions. Securing digital systems.*
